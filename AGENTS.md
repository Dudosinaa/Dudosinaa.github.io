# Инструкции проекта

Статический сайт без сборки, фреймворков и runtime-зависимостей. HTML — в `index.html`, CSS — в `styles/`, ES-модули — в `scripts/`, содержимое — в `content/*.json`, изображения и PDF — в `assets/`.

- Запуск в Windows: `.\start.cmd` (автовыбор Node.js или установленного Python). При доступном Node: `node scripts/serve.mjs`. Адрес http://127.0.0.1:4173.
- Проверка: `node --test`. Установка пакетов и сборка не нужны.
- Не добавляйте биографические утверждения без предоставленных владельцем сведений. Помечайте демонстрационные данные через `isExample`.
- Все пути к локальным файлам должны быть относительными, чтобы сайт работал в подпапке GitHub Pages.
- Проверяйте интерфейс на ширинах 375, 768 и 1440 px, клавиатуру, мобильное меню и состояния отсутствующего контента.
- Сохраняйте обычную прокрутку, поддержку reduced motion, контраст и доступность без анимации.
- Для JavaScript используйте ES-модули, двухпробельный отступ и встроенный `node:test` для содержательных проверок. Дополнительный форматтер не требуется.
