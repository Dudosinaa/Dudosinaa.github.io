На временном локальном сервере из `.qa/` проверены:

- Пустые массивы форумов/статей и ошибки JSON, изолированные в своих разделах.
- Повторная загрузка: оба списка восстановлены, новые карточки наблюдаются.
- DOI, внешняя ссылка и локальный PDF статьи; отсутствующий PDF не создаёт кнопку или пустую строку действий.
- PDF резюме после добавления файла.
- Фокус на PDF-ссылке: родительская карточка имеет opacity 1 и animation none, фокус не перемещается.

- Отсутствие IntersectionObserver: контент загружается и остаётся видимым, навигация работает. Найденная в этом сценарии ошибка проверки конструктора навигации устранена.
- Повтор при прокрутке вниз и вверх: счётчик событий CSS показал переход от одного запуска к двум после полного выхода и возврата. Небольшое перемещение внутри видимой области не увеличивает счётчик. Колебания пересечения внутренней границы также покрыты автотестом.
- Карточка высотой 840 px на экране высотой 812 px: появляется, сохраняет один запуск во время чтения и запускается повторно после полного выхода и возврата.
- Reduced motion в изолированном сценарии: класс появления отсутствует, opacity 1, transform none, декоративная фигура и свечение не анимируются.

В браузере нет API эмуляции системного media feature. Поэтому для reduced motion тестовый сервер задавал соответствующее значение matchMedia и применял тот же CSS-блок reduced motion без условия; системные настройки Windows не менялись. Реальное переключение системной настройки в браузере не проверялось; реакция JS на её изменение покрыта node:test.

Тестовые данные и инструменты в `.qa/` исключены из Git. Основные файлы контента сохраняют только явно обозначенные примеры. Скриншоты обновления: `.qa/updated-desktop.jpg`, `.qa/updated-sections.jpg`, `.qa/updated-mobile.jpg`.
